# 擂台匹配（自动点开始匹配，常驻守候）

用途：打开「擂台大战」面板后，自动等待「开始匹配」按钮出现并点击；点完不结束，
弹窗再出现（队友取消、匹配失败重试、打完一局回房间）就再点一次。

识别器 `leitai_pipei`：全屏 OCR + **锚定关键词**（`^\s*开始匹配\s*$`，只有整段
文本就是「开始匹配」才算命中），单轮最多等待 300 秒，1 秒一帧。命中即返回按钮
命中框，由 pipeline 节点 Click。

## 为什么不能用「包含匹配」+ 固定比例 ROI

* MaaFramework 的 OCR `expected` 是**子串**正则（`boost::regex_search`），
  `cherry_pick()` 默认取**最靠左**的命中框：面板上的说明文字
  「点击开始匹配，队伍满5人开战」同样命中，且排在按钮左边 → Click 点在文字上，
  按钮一次都点不到（v0.1.8 及之前剑会真机就是这个现象，v0.1.9 修）；
* 固定比例 ROI 是按一张横屏截图量的，换分辨率 / 竖屏会整块错开，把按钮排除在
  扫描区外。

锚定之后，「点击开始匹配…」这类说明行连候选都不是；再加上去空白标点后的整段
比对与黑名单（请及时 / 等等 / 取消 / 关闭 / 等待），提示文字一律不会被点。
含「匹配」但不含「开始匹配」的余票提示「队伍组满5人方可开始擂台乱斗匹配」
本来就不命中。

## pipeline

`leitai_pipei`（入口，timeout -1）→ `擂台匹配-保持匹配`（Custom 识别 + Click，
`next`/`on_error` 都跳回自身）。命中点了继续守，没命中下一帧再看，**任务不会
自行结束**；要收工点「停止任务」，识别器收到停止请求立即退出本轮守候。

## 可选参数（custom_recognition_param）

`leitai_enabled` 关掉该节点、`leitai_expected` 自定义锚定关键词、
`leitai_roi` 绝对像素 ROI、`leitai_roi_ratio` 按比例 ROI（默认全屏，免换算）、
`leitai_threshold` OCR 阈值、`leitai_max_wait` 单轮等待秒数、
`leitai_interval` 轮询间隔、`leitai_click_cooldown` 连击冷却（避免同一按钮
被连点两次）、`leitai_notify` 命中通知。
